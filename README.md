# Linux для пользователя

Интерактивный курс про устройство Linux и работу на сервере: пользователи, группы, права, процессы, фон, tmux, пути, команды, файлы, редакторы, ошибки, sudo и SSH.

- Полная версия: [index.html](https://olharashevska.github.io/linux-kurs/) — модели, баллы, замки, повторялка, экзамен.
- Версия для чтения без скриптов: [chitalka.html](https://olharashevska.github.io/linux-kurs/chitalka.html).

Прогресс хранится в браузере, на сервер ничего не отправляется.
